## What you will learn
- Describe the protocol for one standardised test for each component of fitness.
- Explain validity, reliability and limitations of fitness tests.

## Why test fitness?
Testing gives a **baseline**, shows **strengths and weaknesses**, helps you **set goals**, and lets you **monitor progress** by retesting. A test must be **standardised**: the same equipment, surface, instructions and conditions every time.

## One test for each component
| Component | Standardised test |
|---|---|
| Cardiovascular endurance | Multistage fitness (bleep) test |
| Body composition | Skinfold calipers or body-fat scales (BMI is a rough guide only) |
| Flexibility | Sit-and-reach test |
| Muscular endurance | One-minute push-up test (or curl-ups) |
| Speed | 30 m or 40 m sprint |
| Strength | Grip strength dynamometer |
| Agility | Illinois agility run |
| Balance | Stork stand |
| Co-ordination | Alternate-hand wall toss |
| Reaction time | Ruler drop test |
| Power | Standing long jump (or vertical jump) |

## Protocols
### Multistage fitness (bleep) test
![Layout of the multistage fitness test with cones 20 metres apart](images/protocol-beep-test.svg)
Runners shuttle between two lines **20 m** apart, timed to recorded beeps that get faster each level. Your score is the last level and shuttle you reach before you fail to reach the line in time twice.

![Standing long jump protocol](images/protocol-standing-long-jump.svg)

**Co-ordination (alternate-hand wall toss):** stand 2 m from a wall, throw a tennis ball underarm with one hand and catch it with the other, alternating, for 30 seconds. Count the number of successful catches.

**Body composition:** skinfold callipers measure the thickness of a fold of skin at set sites on the body. The measurements are put into a formula to estimate body fat.

## Validity, reliability and limitations
- **Valid:** the test really measures what it claims to measure.
- **Reliable:** you get similar results each time when conditions are the same.
- **Limitations:** results can be affected by motivation, weather, surface, footwear, the tester's skill, and how well rested you are. A single test measures only one component. Some tests (like the bleep test) depend on pacing and effort. Many tests are shown to be most useful for comparison *with yourself* over time.
