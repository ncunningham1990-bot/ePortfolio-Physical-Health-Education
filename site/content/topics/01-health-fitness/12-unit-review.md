Use this to check what you remember from the whole unit. If something is wrong, read the hint, think about it, and try again.

```quiz
Q: Which pair are BOTH health-related components of fitness?
- Reaction time and agility | Check the diagram in lesson 1. Which group are these two in?
+ Cardiovascular endurance and flexibility
- Power and co-ordination | Are these two mainly about performance in sport?

Q: Which test is a standardised test of muscular endurance?
- Sit-and-reach | That test measures a range of movement.
+ One-minute push-ups
- Standing long jump | That measures explosive leg power.

Q: A fitness test gives the same result each time under the same conditions. This shows the test is...
+ reliable
- valid | Valid means it measures the right thing. Does the question talk about consistency?

Q: Which type of graph is best for showing change in fitness over time?
- Bar chart for separate categories | What is being shown: separate groups or change over time?
+ Line graph

Q: VO₂ max is measured in...
- bpm | Beats per minute is heart rate.
+ ml/kg/min
- kg | Kilograms measure mass.

Q: Which method of training uses explosive jumping to build power?
- Continuous | Continuous training is steady and long.
+ Plyometric
- Fartlek | Fartlek is varied-pace running.

Q: Which is a sign of over-training?
- Resting heart rate falls steadily and performance improves | That describes good adaptation.
+ Constant tiredness, poor sleep and slower performance
```

```match
Specificity = Training matches the sport | Which principle is about suitability for the activity?

Karvonen method = Uses heart rate reserve | Which method uses resting heart rate too?
Normative data = Typical scores for a similar group | Which term describes comparison scores?
```
